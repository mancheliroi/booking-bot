# Booking Bot — Telegram-бот для онлайн-записи клиентов

Бот для салонов, мастеров и небольших студий: клиент сам выбирает услугу, день и свободное время, оставляет телефон — администратор сразу получает уведомление.

## Возможности

**Для клиентов**
- каталог услуг с длительностью и ценой;
- выбор дня (выходные скрыты) и только реально свободного времени;
- телефон одной кнопкой «Отправить номер»;
- «Мои записи» и отмена своей записи;
- кнопка «Контакты» с адресом и телефоном.

**Для администратора — управление без программиста**

Всё настраивается кнопками в Telegram по команде `/admin`:
- **услуги и цены**: добавить услугу, изменить название, цену, длительность, скрыть или вернуть услугу;
- **тексты бота**: приветствие, сообщение после записи, контакты — новый текст сразу видят клиенты;
- **расписание**: записи на сегодня и завтра одной кнопкой, `/day 25.10` — на любую дату;
- `/cancel 12` — отменить запись (клиент получит сообщение);
- уведомления о новых записях и отменах.

**Под капотом**
- расчёт слотов учитывает длительность услуги: 2-часовая услуга не встанет за час до закрытия и не наложится на чужую запись;
- повторная проверка слота перед сохранением — два клиента не займут одно время;
- время хранится в UTC, показывается в часовом поясе салона.

## Стек

Python 3.12 · aiogram 3 · SQLAlchemy 2 (async) · SQLite / PostgreSQL · pydantic-settings · Docker · pytest

## Запуск

```bash
cp .env.example .env    # укажите BOT_TOKEN и ADMIN_IDS
docker compose up -d --build
```

Без Docker:

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m app.main
```

Услуги, цены и тексты администратор меняет сам через `/admin`. Рабочие часы, шаг слотов, выходные и часовой пояс задаются один раз в `.env`.

## Тесты

```bash
pip install -r requirements-dev.txt
pytest
```

## Структура

```
app/
  main.py          — запуск бота
  config.py        — настройки из .env
  db.py            — модели и инициализация БД
  repo.py          — запросы к базе
  slots.py         — расчёт свободного времени (чистые функции)
  ui.py            — клавиатуры и форматирование
  handlers/
    user.py        — сценарий записи для клиента
    admin.py       — панель администратора: услуги, тексты, расписание
tests/             — тесты слотов, базы и парсинга дат
```
